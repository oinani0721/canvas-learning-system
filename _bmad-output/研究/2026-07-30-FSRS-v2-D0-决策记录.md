# FSRS v2 第 0 步决策记录

## [Decision-FSRS-1] grade→Rating 四档映射（前置②，拍板）

- `abandoned: true` → **Rating.Again(1)**（弃答 = 一等失败信号，一票否决）
- 否则还原连续分 `grade = 1 + 3 × grade_norm`（quiz-answer 的 grade_norm 本就是 4 维 rubric 1-4 均值的归一化），按官方四档就近落档：
  `< 1.5 → Again(1)` · `< 2.5 → Hard(2)` · `< 3.5 → Good(3)` · `≥ 3.5 → Easy(4)`
- **理由**：无损自然映射，不引入新评分 UI；调度器参数保持 py-fsrs DEFAULT_PARAMETERS + `desired_retention=0.9` + `enable_fuzzing=False`（可复现、可测试；fuzzing 等个人化拟合 F6 一并评估）。
- 单一真相源：`canvas-vault/.claude/scripts/fsrs_bridge.py::rating_from_grade`，测试锁边界。

## [Decision-FSRS-2] WHEN/WHAT 双引擎分工（前置⑤，钉死防双主干撕裂）

- **FSRS 管 WHEN**：`fsrs_due` 决定「今天谁到期」。节点无 `fsrs_due` 字段 = New 卡**即刻到期**（零迁移：17 个存量节点首日行为与 MVP 完全一致）。
- **衰减 Beta 管 WHAT**：到期集合内按 `pick = μ − σ`（含闲置回升）排序，板级 `min(pick)`。衰减 Beta 不再承担任何日程语义。
- **全员未到期 → 推送放假消息**（「今天没有到期节点」），`今日复习.md` 列出最近的未来到期日。
- **写侧唯一入口 = quiz-answer 本地链**（经 fsrs_bridge）。后端 MasteryStore/Neo4j 的 p_mastery/fsrs_* 状态**禁止启用写入**——审查已实证其为死链且与 frontmatter 分叉，Tier B 退役完成前后端侧只许读不许写（防 3-4 份真相源）。
- frontmatter 加性字段 6 个（无破坏性迁移）：`fsrs_due / fsrs_state / fsrs_step / fsrs_stability / fsrs_difficulty / fsrs_last_review`。
- 读侧（daily_review_pick / Dashboard Dataview）**保持纯 stdlib/前端**，只做字符串日期比较，不 import fsrs——调度计算全部收拢在写侧 bridge（launchd 环境仅 stdlib 的既有契约不破）。
