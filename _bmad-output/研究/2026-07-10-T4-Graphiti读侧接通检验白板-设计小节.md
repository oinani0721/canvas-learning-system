## 三 · 方案选项

### 方案 A（推荐）· 后端素材 API + skill 可选 curl

```
POST /api/v1/exam/targeting-material   (X-CLS-Internal-Key 鉴权)
请求: { node_id, vault_id, max_hops: 1, budget_chars: 1200 }
响应: { materials: [ { source_node, relation_reason, kind: error|tip, text, last_seen } ], degraded: bool }
```

- 后端新增一个只读端点：沿 `CanvasNode-[CANVAS_EDGE{label}]->CanvasNode` 找 1-hop 邻居 → 对每个邻居调既有 `read_node_errors` / `read_node_tips` → 拼素材列表（截断到 budget）
- skill Step 5 出题前**可选**加一步：`curl -m 5 … || 降级`，拿到就把 `[NEIGHBOR_ERROR]` 素材块并入出题 prompt；拿不到（后端离线/超时/空）→ 完全退回现行为
- **为什么推荐**：与 enrich-hook 完全同构（curl + key + 静默降级的先例已在 settings.json 验证过）；skill 铁律不破（见 §四）；后端复用 T1/T2 打通的读链，新代码 ≈ 一个端点 + 一个查询函数

### 方案 B · MCP 工具（exam ACP MCP server 加 read_targeting_material）

- 加到 `backend/app/mcp/tools/exam_tools.py`，Claudian 经 MCP 调用
- 优点：类型化契约；缺点：依赖 Claudian MCP 配置就绪（headless/新装机器可能没有），且 skill 说明书需要教 Claude 何时调 MCP——降级路径不如 curl 直白

### 方案 C · 不做跨节点，等 belief 版本链

## 四 · 铁律怎么守（重点批注区）

1. **信息隔离（d=1.50）**：素材**只含**邻居节点的错误描述/批注原文/派生原因——这三样都是"学生自己写的/AI 归纳的错误"，**不是定义正文**。后端读器本来就是字段级（`read_node_errors` 读 frontmatter errors[]，不碰 `## 核心概念`）。检验白板内容照旧不进检索。
2. **skill 诚实边界**：skill 不直连 Neo4j/不 import 后端代码——只多一条**可选** curl（与 enrich-hook 同款），HTTP 契约即边界。
3. **离线可用不破**：curl 失败/超时/空响应 → 素材块不出现，出题流程与今天完全一致。
4. **HARD-SILENT**：素材只进出题 prompt，不在白板上显示来源节点的评分。
