# Canvas Learning System 核心功能盘点（2026-07-22）

> [!info]+ 一句话总评
> **你今天手上是一个「输入端很顺手、评估端刚跑通、但反馈闭环还没接上」的个人学习系统**——批注、派生、建白板、检验白板出题+评分这条主动回忆主链（系统灵魂）真能用了；但让它「越用越懂你」的三根神经（错误自动记忆、复习调度、熟练度融合）都还差最后一段接线。所以它现在是**一台能考你、但还不会因材施教的机器**——而计划 MEM-FLYWHEEL 的批次 1-2 修的正是这三根线里最值钱的两根。

## 一、已实现且真能用（今天就能上手，全部过 UAT 或真机验证）

| 功能 | 怎么用 | 价值一句话 |
|---|---|---|
| **批注（7 类 callout）** | `Cmd+Shift+A` | 选中文字一键标疑问/错误/Tips，学习痕迹当场沉淀（且自动入图谱） |
| **派生新概念节点** | `Cmd+Shift+D` | 把一段话「拉出来」成独立节点+自动挂双链+记录派生原因，线性笔记织成知识网 |
| **插入新疑问** | `Cmd+Shift+S` | 随手记疑问，下次检验白板能反向考到你 |
| **建/配置原白板** | `Cmd+P` → 建/配置原白板 | 从零或从任意 md 一键建学科学习地图 |
| **追加笔记到白板** | `Cmd+P` → 追加到已有原白板 | 散笔记归拢进学科白板 |
| **Dashboard + 一键考察** | `Cmd+P` → 打开 Dashboard | 总览所有白板，点「🚀 考察」直接开考 |
| **检验白板出题（灵魂）** | `/start-exam-board from <白板>` | 信息隔离主动回忆，引用你自己的批注原话出针对题 |
| **静默评分 + 疑问归纳** | 答完输 `/quiz-answer` | 4 维延迟反馈评分 + 掌握度演化 + 新疑问自动归纳回节点 |
| **快速单题 fallback** | `/exam-quick` | 后端出题挂了也能拿到一道针对批注的练习题 |
| **节点 AI 对话** | `Cmd+P` → 节点对话 / `/node-chat` | 围绕某概念连贯提问，自动带节点正文+邻居上下文 |
| **上下文对话/解题模式** | `/chat-with-context`、`/study-question` | 提问自动召回讲义片段；解题给「定义/直觉/反例/联系」四段拆解 |
| **错误候选复盘** | `Cmd+P` → 复盘错误候选 | 对系统提名的「你可能的误解」逐条 accept/dispute，用户主权 |

## 二、部分实现（能用但缺关键一半）

| 功能 | 能用的 | 缺的 | 对应计划 |
|---|---|---|---|
| 笔记精准检索（RAG） | 提问自动注入笔记片段（LanceDB 路） | Graphiti 记忆通道静默空转（三死因） | 批次 1 线 3 |
| 熟练度/越考越准 | 出题+评分闭环通、mastery 会更新 | 恒权 EMA 不收敛，考 100 次精度=3 次 | 批次 1 线 1（A1） |
| 错误候选复盘 UI | 三态卡片+Dashboard 列表真能点 | **无自动提名**——弹药只出不进，测试种子耗尽即枯死 | 批次 2（P14） |
| 历史错误提醒 | 设计+格式化器+测试全在 | `search_error_memories` 方法本体不存在 → 现网 500（回归 bug） | 后续轨道（原修复排序第 4） |
| 记忆召回体感 | 写侧勤快，当天写当天可召回 | 读侧仅 2 路、确定性触发仅 1 路 | 批次 1 线 2 |
| 学习辅助 skill（四层次/例题/变式） | 全局 Claude Code 可调 | 未迁入 canvas-vault，没接进学习流 | 待排（V2 波次 1，S 级） |
| 一键注入 full-RAG | Claudian 直输路径活 | plugin 热键 `Cmd+Shift+C/E/Q` 的注入路从未实现 | 待排 |
| Dashboard | 列表+考察按钮+候选列表 | 无校准矩阵；「复习队列」是死端点永远空 | 待排（Epic 8） |

## 三、高生产力价值未实现 TOP（按对学习效率的影响排序）

| # | 功能 | 为什么值钱（大白话） | 状态/量级 |
|---|---|---|---|
| 1 | **错误候选自动提名（P14）** | 聊天里暴露的误解被系统自动记住、下次专门考你——不接，复盘 UI 和最强记忆体感都会枯死（95% 投入已沉没，只差 5%） | **批次 2 在做**，S |
| 2 | **FSRS 驱动复习时机** | 在你快忘的临界点自动提醒重考——间隔效应 d≈0.55 的兑现处；现在复习队列永远是空的 | 最小版 M（可先做 skill 本地版） |
| 3 | **五信号熟练度融合（C3）** | 掌握度从拍脑袋变成随证据越来越准，出题自动收敛到最弱点 | 后续轨道，L |
| 4 | **Epic 7 错误修正+间隔复习** | 犯错→到期重考→确认已纠正的最后一环；错误不再靠你自己想起来复盘 | 半边已做（轨道B），剩时间维度 L |
| 5 | **search_error_memories 修复** | 回答前先提醒「你以前在这栽过跟头」；且是现网 500 顺手止血 | M |
| 6 | **学习辅助 skill 迁移** | 四层次/例题/变式接进 Claudian 才是完整学习助手而非只会出题 | S，零依赖 |
| 7 | **RAG Graphiti 通道 + search_memories 触发** | 「提问自动召回记忆」从假变真 | **批次 1 在做**，S-M |
| 8 | **校准投票 UI** | 给 AI 评分打分，元认知纠偏的唯一数据来源 | M，需设计确认 |
| 9 | **4 级渐进提示 + 跳过** | 答不出给阶梯提示——你批注里点名过的「灵魂设计空洞」 | L，需设计确认 |
| 10 | **2x2 校准矩阵 Dashboard** | 暴露「自以为懂 vs 实际不懂」象限 | M-XL，等数据量 |
| 11 | **图片识别检索/出题** | slides 截图是高频材料，现在游离在外（后端 1611 行已就绪） | M |

> V2 盘点已裁决「决策性放弃」的不列入（图片出题 9.1、审计日志、多用户等）——砍得对，不用再决策。

## 四、与今天开工的计划怎么对上

批次 0（已完工，见验收单）保「记录不丢」；批次 1 修 TOP 7 + 收敛地基；批次 2 修 TOP 1；TOP 2/3/4 是批次 1-2 攒够数据后的后续轨道——顺序上「先保数据、再准出题、后调节奏」，与价值排序一致。
