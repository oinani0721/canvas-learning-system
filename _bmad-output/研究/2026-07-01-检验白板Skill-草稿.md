**User：这里有一个问题，我的检验白板基本上是我选择对原有的原白板来分析后进行出题考察我，那么我的节点熟练度，决定了你怎么出题考察我，从而确保我真的掌握了相关的知识，这里你的出题要怎么设计，我的建议是你把相关设计给 ChatGPT 来 deep reasearch ，因为我是要一个真正有效的考察，通过你的检验白板的考题，最大限度的让我掌握相关的内容**
   
2. **出题数据 = 只读 frontmatter，不读正文**：你的批注在 `tips[]`、派生原因在 `relationships[]`（我 P1 的成果都在 frontmatter）。Skill **只读 frontmatter 的批注/原因/掌握度出题，不读节点正文定义**（保信息隔离，d=1.50 命脉）。
3. **评分才读正文**：评分发生在你答完之后，此时才允许读节点正文当"标准答案"给分——不违反隔离（你已答完，不再看原文）。
4. **熟练度更新走 MCP**：评分后调 `update_bkt`/`update_fsrs`（纯数据、喂后端熟练度引擎）→ `query_mastery` 拿融合值 → Skill 把 `mastery_level`/`fsrs_next_review_at` 写回节点 frontmatter → Dashboard Dataview 读它反馈（**不是节点变色**）。
5. **触发**：Claudian 侧栏 或 claude code CLI 输 `/start-exam-board`；答完输 `/quiz-answer`（或以后接 Cmd+Option+S 快捷键）。

# 检验白板生成 Skill v1.0（Canvas Learning System · 灵魂功能）

## ⛔⛔⛔ CRITICAL — 信息隔离铁律（违反 = Skill 失败）

- **HARD-ISO-1**：绝不把节点**正文定义**打印到侧栏/对话。出题只用 frontmatter 的
  批注(tips)/原因(relationships)/掌握度，不用正文。
- **HARD-ISO-2**：检验白板 md 里**只有题目 callout**，不含任何概念定义/答案/原文。
- **HARD-ISO-3**：回执里提醒用户"答题时不要切 Tab 去看原文"（切了 d=1.50 → 0.40）。

## Step 1 · 防嵌套检查
- 读当前活动文件 frontmatter。若 `type == exam_board` 或路径在 `检验白板/` 下
  → **拒绝**："⛔ 已在检验白板内，不能再生成检验白板。请回到 原白板/ 再触发。"

## Step 2 · 确定源原白板
- 有 `from <名>` 参数 → 用 `原白板/<名>.md`
- 无参 → 用当前打开的 `原白板/*.md`；当前不是原白板 → AskUserQuestion 让用户选一个原白板

## Step 3 · 选最薄弱节点（读 frontmatter，不依赖后端）
- Read 原白板 md 的 `## Concepts`，取所有 `[[节点/X]]`
- 对每个节点 Read frontmatter 的 `mastery_level` + `fsrs_next_review_at`
- 选：**mastery_level 最低**（优先 fsrs_next_review_at ≤ 今天的"已到期"节点）
- 全部无 mastery 数据（新白板）→ 选第一个 / AskUserQuestion

## Step 4 · 拿针对性数据（只读 frontmatter + 可选 MCP，不读正文）
- Read 目标节点 frontmatter：`tips[]`（你的批注）、`relationships[]`（派生原因）
- 可选：`search_memories(node_id)` 拿错误历史（Graphiti）
- **不 Read 节点正文**（HARD-ISO-1）

## Step 5 · 【Claude Code 订阅出题】
- 基于批注/原因/掌握度，生成 **1 道针对性题**，**显式引用你的批注原话**
  （例：「你之前批注说『代理就是能感知环境的实体』，那它和"理性代理"的区别你怎么界定？」）
- 难度按掌握度适配（低→理解题，高→分析/评价题）
- **HARD-Q-1**：题目不含答案/定义；**HARD-Q-2**：不把出题依据的原文倒进侧栏

## Step 6 · 写检验白板 md
- 路径：`检验白板/<board-slug>-<yyyy-mm-dd-hhmm>.md`（**HARD-PATH**：必须 检验白板/）
- frontmatter：`type: exam_board`（防嵌套）+ source_canvas + selected_nodes + questions[q1] + status: in_progress
- 正文只放：
  ```
  > [!exam_question]+ Q1 · <节点>
  > <出的题>
  >
  > 答：
  > (在这里手写你的回答)
  ```

## Step 7 · 回执（不泄漏）
```
✓ 检验白板已建：检验白板/<file>.md（已打开）
✓ 本次考察节点：<节点>（当前掌握度 <level>，已到复习期）
→ 在"答："下手写你的回答（像打批注一样）
→ 答完输 /quiz-answer 评分（静默，不显分）
⚠ 答题时别切 Tab 看原文 — 那会破坏主动回忆效果
```
````

# 检验白板评分 Skill v1.0

## ⛔ 静默铁律
- **HARD-SILENT**：绝不显示分数/评分给用户（不在侧栏输出分、不弹通知、md 里不追加"评分"段）。
  分数只写进检验白板 md frontmatter questions[].score（用户不主动看就看不到）。

## Step 1 · 提取答案
- Read 当前检验白板 md（frontmatter type==exam_board 确认）
- 正则提取最后一个 `[!exam_question]+` 的 `> 答：` 后内容
- 若还是占位符 `(在这里手写你的回答)` 或空 → 提示"你还没作答"，停止

## Step 2 · 【Claude Code 订阅静默评分】
- 此时**允许 Read 节点正文**当标准（你已答完，不违反隔离）
- 4 维 4 分制打分：概念准确 / 推理质量 / 知识覆盖 / 知识整合（各 1-4）
- 取均值 → grade（1-4）

## Step 3 · 写分到 frontmatter（不显示）
- Edit 检验白板 md frontmatter questions[q1].score = 各维分 + 均值

## Step 4 · 更新熟练度（纯数据 MCP，喂后端引擎）
- `update_bkt(node_id, grade)` → 更新掌握概率
- `update_fsrs(node_id, quality=grade)` → 更新稳定性 + 算 next_review_at
- `query_mastery(node_id)` → 拿融合后 mastery_level + fsrs_next_review_at
- Edit 节点 frontmatter：写回 `mastery_level` + `fsrs_next_review_at`（供 Dashboard Dataview）

## Step 5 · 回执（静默 + 引导）
```
✓ 已记录（本次考察完成）
→ 打开 Dashboard 看掌握度变化与下次复习建议（静默评分，此处不显分）
（考中若发现某概念不懂：别切 Tab，在检验白板里插一行
  > [!discussion_later]+ 📌 待剖析 [[节点/X]]，考完再去原白板剖析）
```
## 单题 MVP 边界
- 本版**出 1 道题就停**（不自动循环下一题）。多题连续、考后校准投票、书签自动拉节点 = 后续。
````
