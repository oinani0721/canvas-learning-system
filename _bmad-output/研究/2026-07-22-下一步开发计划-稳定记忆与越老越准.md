## 1. 现状诊断（4 路审计合成，全部带行号证据）

### 1.1 拆分过程：时间锚扎实，但缺「理解快照」，且会越老越脏

**已经做得好的**：每次 Cmd+Shift+D 派生有 3 处真实时间戳（节点 frontmatter created_at / 白板 Recent Activity ISO 行 / 主图边 valid_at），且专门防启动回填覆盖真实时间——「这个白板何时、从哪、为什么拆出这个节点」今天就能还原。

**三个洞**：
1. **理解状态快照没记**——派生瞬间你对源节点的掌握程度、正在困惑什么，都没随边记录（mastery 硬编码 0.3）。「当时为什么困惑」是越老越准的核心素材，事后无法重建。
2. **出题侧读的投影图完全无时间维度**——CANVAS_EDGE 没有任何时间字段，出题时看不到拆分时序；派生条目也无顺序号。
3. **改原因/删节点/重命名全部无对账**——改派生原因会在主图多出一条边（旧边不失效）、删节点和改名后旧边永久残留。**拆分时间线会越老越脏，正好是「越老越准」的反面。**

（另一发现：ai-linked-doc Skill 已不在派生主链上，派生是 100% plugin 脚本完成，SKILL.md 是历史残留——文档需更新以免误导。）

### 1.2 考察过程：内容素材在积累，统计证据没在积累

现在**真正影响下次出题的只有两条**：mastery_score（选最弱节点）+ 答题后归纳回节点的疑问 callout（下次出题素材）。其余全是收集了却没人用，或根本没收集：

| 数据 | 现状 |
|---|---|
| calibration_log[]（自评 vs 实评） | ✍️ 一直在写，**全仓零代码读它**（write-only 死数据） |
| 检验白板 md（每场题面/得分/自评，累积不覆盖） | 天然的考察历史档案，**出题侧从不回读** → 无题目去重，系统不知道「这节点考过几次、上次考了啥」 |
| 弃答（「我不会」） | 答案空直接停止，**信号被静默丢弃**（P12） |
| dispute 裁决（「AI 判错了」） | 只改 candidate 状态，**下游出题永远看不到**，可能再拿同一个被你否认的点考你 |
| mastery_score 本身 | 恒权 EMA，数学上**不收敛**——考 100 次和考 3 次的估计精度一样（N_eff≡3），且低分节点会被锁死循环考 |
| 蒸馏出的错误（P14） | classify 返回值直接丢弃，**错误候选生产端为零**，你最强体感路径弹药只出不进 |

### 1.3 底座：四个缺口不变 + 一个新证据

零备份、日志随容器蒸发、中文白板名影子图归档 100% 失败（死信实锤）、SessionEnd 停机窗口归档永久丢——这四个 07-20 已确认；今天 12341/18012 静默死亡是第五个现场证据：**自启和健康监控的范围必须覆盖宿主本地模型进程，不只是 Docker**。

## 2. 学术与工程实证（DD-01，全部带来源，已逐条查证）

1. **「记录真实错误」有反向铁证**：LLM 生成的干扰项在数学上有效但**不反映真实学生的迷思**（arXiv:2404.02124）——AI 猜不出你的错法，只有你的 errors[] 能提供。这从学理上钉死了你的方向：记录考察过程不是锦上添花，是针对性出题的唯一数据来源。
2. **高置信度错误纠正收益最大**（Metcalfe, Annual Review of Psychology 2017）→ errors[] 值得加一个「答错时的自信度」字段（我们 calibration_log 已在收，只差消费）。
3. **重复同题只测「答案记忆」**；交错变体的整群随机试验效应量 **d=0.83**（Rohrer 2020, J. Educational Psychology）→ track-A 的题目去重 + 变体是高回报投入。
4. **掌握度模型保持浅层就够**：扩展版 BKT 与深度学习模型性能无差别且可解释（Khajah et al., EDM 2016）；FSRS 在 3.5 亿条真实复习记录基准上碾压 SM-2。**当前瓶颈是数据链断裂，不是模型不深**——先修管道，别上神经网络。
5. **过程记录的工程正解是轻量事件日志**：Fowler 的 event sourcing 定义（「可丢弃全部状态、从事件日志重建」）+ 他对简单系统的明确告诫 → 单机场景一个 append-only JSONL + 幂等键 + 重放脚本就达到全部核心保证，不需要任何重型组件。
6. **可靠性官方姿势**：Neo4j Community 版唯一官方备份 = 停机 → `neo4j-admin database dump` → 重启（在线备份是 Enterprise 专属）；Docker Desktop macOS 自启设置有失效前科（docker/for-mac#7073），需 Login Items 双保险 + 应用层健康检查。
