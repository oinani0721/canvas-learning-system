## 三、FSRS v2 = 8 个用户可感知功能（验收对象本体）

按边际价值排序（⚔ = 对抗性修正过的判断）：

| # | 功能 | 你屏幕上的变化（UAT 措辞候选） | 前置 |
|---|---|---|---|
| F1 | **真实到期日预测**（Card.due + 回忆概率）⚔ 边际价值最高：衰减 Beta 只会排「今天谁第一」，永远说不出「今天其实不用复习」 | Dashboard「FSRS 到期」从占位变真实列表；推送能说「今天到期 N 个」；**没到期时推送放我一天假** | ②③④（①不阻塞，默认参数即可跑） |
| F2 | 最优扩张间隔（1→3→8 天指数拉长） | 连续答对的节点从推荐里消失得越来越久，「今日复习」多一列「下次到期」 | ②③④ |
| F3 | 当日重学环（答错→10 分钟级短间隔） | 答「不会」的节点**当天稍后就再次出现**，不用等明天 9:05 | ②④ |
| F4 | 节点难度分化（per-card difficulty） | 两个分数相近的节点，屡错的那个明显更频繁出现；节点可见「难度」字段 | ②③④ |
| F5 | **4 档评分语义**（Again/Hard/Good/Easy）⚔ 成本最低、解锁面最大——quiz-answer 已有 grade(1-4) 中间值，round 映射半天可拍板，**是其余全部功能的公共前置，应最先做** | 轻松秒答的消失特别久（Easy 跳增），勉强答对的很快又来（Hard 缩短） | ② 映射拍板 |
| F6 | 个人化参数拟合 ⚔ 唯一真被 review log 卡死的功能（现 4 条全 0 分单节点）；不阻塞 v2 上线，原料随 MVP 自动积累 | 用一两个月后推荐越来越「踩点」；Dashboard 显示「已用你的 N 条记录个性化」 | ①（距离最远） |
| F7 | 历史重放（reschedule_card） | 升级/调参后一键重算全部到期日，掌握历史一条不丢 | ①③ |
| F8 | **双真相源收口 + 死管道退役**（治理项）⚔ 不做这项，上线后系统同时存在 3-4 套「复习真相」 | Dashboard 不再挂「暂未实现」免责声明；**全系统只有一种到期口径，在哪看到的数都一致** | ⑤⑥ |

**FSRS v2 验收单（4-B 草案，开发完成后正式 ship）**：
- [ ] 我打开 Dashboard → 「到期」数字是真的，点开能看到具体节点和日期 → 我感觉日程是可信的（F1/F8）
- [ ] 某天所有节点都不到期 → 早上推送说「今天不用复习」→ 我感觉系统不是在没话找话（F1）
- [ ] 我连续几次轻松答对某节点 → 它消失的间隔明显一次比一次长 → 我感觉它不再纠缠我会的东西（F2/F5）
- [ ] 我答「不会」→ 当天稍后它就再次出现在推荐里 → 我感觉系统在趁热补漏（F3）
- [ ] 屡次答错的节点比同分数的其他节点来得更勤 → 我感觉它认得出「这个对我特别难」（F4）
- [ ] 我在任何入口（Dashboard/推送/今日复习.md）看到的到期信息口径一致 → 我感觉这是一个说话算数的系统（F8）
- [ ] 回归保护：推送轮转、检验白板信息隔离、静默评分、衰减 Beta 排序全部行为不变
