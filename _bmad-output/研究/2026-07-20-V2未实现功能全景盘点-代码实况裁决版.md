## 一、五个高杠杆发现（裁决过程中修正的认知差）

1. **C0「最大工程债」已经塌缩** ⭐ — 文档一直写"main 领先 232 commits 的分叉合并"，实测方向已反转：worktree 领先 237，**待并的只剩 main 独有的 6 个 commit**（含 Fix-D node_id-keyed 直写——"批注→针对性考察"主链的写侧关键环）。全场最划算的一次解堵，做完 C 轨道从空中楼阁变可排期。
2. **search_error_memories 是回归不是欠账** — 它 2026-05-13 曾 ship 过（87/87 tests），在 worktree 演化中丢失；现在 chat.py 调一个不存在的方法，/enrich-context 现网 500。文档存在感只有一行，实际是波次 1 止血件。
3. **错误候选自动提名只差 5%** — 轨道 B 刚建好的三态卡片/accept/dispute/Dashboard 全套 UI，目前只有一条手造测试数据在空转。全生命周期后端已 100% 就绪，缺的只是把 SessionEnd 蒸馏出的 errors 走 candidate_only 写入（S 级接线 = P14 同一落点）。
4. **三个「灵魂设计空洞」无 descope 记录** — Edge 对话 EI+SE（d=0.80-1.00，效应量第二大）、4 级渐进提示+跳过（你批注原话"我记得有跳过等选项"）、节点切换隐形评分——PRD §1 标了效应量的设计，换轨时被静默丢弃，§12 无对应决策。要么补拍板做、要么正式 descope 闭账。
5. **D1-D13 决策区全部空勾** — PRD §12 只有 D14 打了勾。13 个悬置决策是所有"需设计确认"项的总源头，半小时勾选可消除后续 session 方向误判。
