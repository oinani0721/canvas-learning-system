> **User: 我们现在全职不是都没有用 Gemini 吗？我们考察的时候都是用 claude code ，那么至于我们 Graphiti 本身需要使用配布的模型，是否可以使用 claude code ，还是我们使用本地模型来执行**

## 一句话核心结论

你的直觉基本正确：**考察主链确实 100% 用你的 Claude Code 订阅**，全栈真正在花 Gemini 钱的只有一个角落（你手动触发的 Quick Exam，实测总共花了 **$0.0007**）；Graphiti 的 Gemini 是「挂名不干活」的名义依赖（实际调用次数 = 0）；**换 Claude Code 订阅不可行**（官方封禁代持，铁律 5），换本地模型可行但当前没必要——所有推荐都是「保持现状」，退路已探明备好。

## 一 · 全栈模型使用地图（全部真机实证）

| 链路 | 用什么模型 | 实际流量 | 花钱吗 |
|---|---|---|---|
| **考察主链**（/start-exam-board 出题、/quiz-answer 评分、/exam-quick 后备） | **你的 Claude Code 订阅** | 你每次考察 | ❌ 订阅内 |
| **检索**（enrich-hook 自动注入、笔记索引、图谱搜索的向量） | **本地 bge-m3**（你 Mac 上的 Ollama） | 每次提问/索引 | ❌ 本地 |
| **Graphiti 记忆写入**（批注/派生/错误入图） | **零模型** — 确定性代码直写，不经过任何 AI | 每次批注/派生 | ❌ 无 |
| Graphiti 语义抽取通道 | Gemini 2.5 Flash（启动时装配好待命） | **0 次调用**（日志实证 'Episode processed' = 0） | ❌ 挂名 |
| **Quick Exam 出题+评分**（Cmd+P 手动触发的练习旁路） | Gemini flash-lite | 实测 4 次 / 1058 tokens | ✅ **$0.0007**（总计） |
| 其他休眠链路（图片 OCR、关系建议、旧对话面板等） | 各有配置 | 当前零流量 | ❌ |

**回答你的第一问**：不是"全栈没用 Gemini"，而是"Gemini 只在一个你手动触发的低频角落"——按现在的用法，云端模型月花费 **不到 1 分钱**，且完全在 Gemini 免费额度内（余量差 2-3 个数量级）。

## 二 · Graphiti 能用 Claude Code 吗 — ⛔ 订阅不行，API 可以但没必要

**先分清两个"Claude"**：
- **Claude Code 订阅** = 你按月付费的会话额度，只能在 Claude Code/Claudian 的**会话里**用。把订阅凭证交给后端服务代持调用 = Anthropic 官方明令封禁的行为（我们的任务书铁律 5）。**这条路永远不通**。
  - ⚠️ 调研还发现代码库里有一个休眠的违规残留：对话蒸馏器里有一档配置指向"订阅代持代理"（容器未运行）——已标记**不可启用**。
- **Claude API** = 单独买的按量付费 key。graphiti_core 官方支持 Anthropic client，技术上可换——但给一条**零流量**的通道换模型，是为不存在的调用付重构成本。

**好消息是你已经在"用 Claude 考察"了**：出题和评分的主体验（/start-exam-board、/quiz-answer）本来就跑在你的订阅里、不经过后端——这些路径的质量还高于 flash-lite。

## 三 · 能用本地模型吗 — 可行，退路已备好，但两个场景都推荐保持现状

**场景 1 · Graphiti 语义抽取**（当前零流量）：
- 推荐 **保持现状不动**——为 0 次调用做迁移没有收益
- 若未来激活这条通道：社区实证（graphiti issues #868/#796 + Zep 官方文档）**8B 级小模型是重灾区**（过不了 Graphiti 的多轮结构化校验，JSON 缺字段），正确做法是复用你 Mac 上已在跑的 **qwen3.5:35b**（结构化输出遵从率和中文能力都够，改造仿照已有的 embedder 工厂模式，1-2 天）

**场景 2 · Quick Exam 出题+评分**（唯一真实 Gemini 流量）：
- 推荐 **保持 Gemini flash-lite**——免费额度内、B1 修复后链路刚稳定
- 若想减少 Google 依赖（我们吃过一次它的地理封锁亏）：**一行配置切 Claude API**（`AI_PROVIDER=anthropic` + claude-haiku + 独立付费 key，代码零改动，天天用也就每月几美元）
- 不推荐换本地模型做这个：为省 0 元引入中文出题质量和评分一致性风险，不划算

**顺带已本地化的**：向量检索（bge-m3）早在 6 月就因 Gemini 地理封锁切到了你的 Ollama，运行日志确认生效中——这部分你已经在"本地模型执行"了。
