## 方向② · "写入+检索记忆完全启动" — 方向对，但激活方式必须改

**最重磅发现（BROKEN）· 双写污染在机制上必然发生**：如果把你的批注事件直接灌进语义抽取通道，graphiti 的去重机制（按 group 全域搜索）会把 LLM 抽取的实体**合并到你现有的确定性记忆节点上，并用 LLM 重写节点摘要**——甚至可能把结构化边标记失效。你的记忆主图（批注/派生/错误的 canonical 记录，也是检验白板出题的燃料）会被 LLM 的理解慢慢侵蚀。**这不是概率问题，是机制必然**（graphiti 源码 node_operations/edge_operations 的 group 边界实证）。

**修正设计 · 双图隔离**：语义通道写进独立的**影子图**（`vault:canvas_vault:semantic` 兄弟分组）——去重和失效判定天然以分组为边界，跨图污染在机制上不可能。检索时双图同查，你两边的记忆都能被搜到。

**"完全启动"的诚实重定义**——审查发现你的批注/派生/错误**已经在"完全写入"了**（确定性直写，可靠且零成本），把它们再灌一遍语义通道 = 纯污染零收益。语义通道真正该接的是当前**彻底缺失**的一条管道：

- ✅ **该开**：**对话归档 → 蒸馏 → 语义抽取入影子图**——你和 AI 的学习对话里的隐式关系、细粒度概念，这是结构化直写给不了的，也是你 6 月 10 日拍板"对话全文走 add_episode"至今唯一没兑现的部分（低频、高信息密度，正适合本地大模型慢慢消化）
  **User：那么关于这一点你打算怎么实现，你这个相当于挂了一个 Graphiti MCP 来随时的进行写入吗？**

  > **[A4 2026-07-13 → round4]** ✅ 不是。官方 Graphiti MCP 有两个机制级缺陷（写入时机靠 Claude 自觉必漏记 + 分组参数可被覆盖导致影子图隔离失守）。真正实现是「下课铃自动录音」式：会话结束钩子（机器触发，vault 已有成功先例）把对话记录送后端确定性管道——蒸馏流水线大半已建好，唯一断点补一个钩子即通，分组由服务端代码写死进影子图，Claude 无权插手。~1 人天，就是 Phase 2。详见 [[R4-Q2_对话记忆写入实现设计-不挂MCP用归档钩子|📚 R4-Q2]]
- ✅ **该开**：检索双图同查 + 后台链（归档调度、对话继承）开 reranker 精排
- ⛔ **不该开**：批注事件二次灌语义通道（污染主图）；实时对话链开 reranker（3 秒预算装不下）

## 方向③ · Quick Exam 切 Claude Code — 正确姿势是"吸收"而非"改造"

**审查戳破的两个迷思**：
- "Cmd+S 保存即评分的无缝体验很宝贵" → 实际上这条闭环 **3 天前才第一次真正能跑**（B1 修复前出题恒模板题、评分恒 502），而且它本身脆弱（后端一重启评分就 404、Obsidian 重载后监听失联）。你从未真正拥有过它，谈不上失去。
- "把 /exam-quick skill 升级来接管" → 那等于推翻它全部设计约束（不写文件/不评分），实质是重写，而且写完和现有的检验白板流程几乎完全重合。

**修正设计 A' · 吸收**（推荐，审查三条路径后胜出）：
1. `/start-exam-board` 加一个 **`node <节点名>`** 参数（~20 行 skill 改动）——你站在某个节点上想快速考它，直接指定，跳过"选最薄弱节点"步骤，其余全链（安全抽取、信息隔离、/quiz-answer 静默评分、掌握度演化）原样复用。**出题和评分从此全在你的订阅里，且比 Gemini flash-lite 质量高**
2. 插件的「Quick Exam」命令改为引导范式：自动复制 `/start-exam-board from <板> node <节点>` + 打开 Claudian，你粘贴即考（与「启动考察」同款交互）
3. `/exam-quick` 保留为**零留档口头抽查**（它的独立价值就这一个：5-10 秒不写文件的快速问答）
4. 后端 Gemini 出题/评分管道在你 UAT 通过后摘除（之前保留作回退保险）
5. 可选 v1.5（~2h）：答完题保存时自动弹提醒 + 复制好 `/quiz-answer`——半自动找回"保存即评分"的体感（差一次粘贴）

**顺带说明**：额外好处是连 Quick Exam 也获得信息隔离保护（后端版会读节点全文出题，有"复读定义"的送分题风险；skill 版走批注定向抽取）。
