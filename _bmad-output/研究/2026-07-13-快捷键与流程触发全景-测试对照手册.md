# 快捷键与流程触发全景 — 测试对照手册（2026-07-13）

> **产出方式**: 3 路并行 agent deep explore（插件源码+你 vault 实绑状态 / 全部文档宣称 / 两流程逐步映射），全部结论带 file:line 证据。
> **一句话结论**: 你的键盘上**真正绑定的快捷键只有 2 个**（Cmd+Shift+A 批注、Cmd+Shift+D 派生），其余操作走命令面板（Cmd+P）或 Claudian 斜杠命令——这是设计使然（插件 12 条命令默认全不绑键，留给用户自绑），但文档里宣称的另外 5 个键全部落空，测试时别被误导。

## 一 · 你现在真正能按的键（实绑 2 个 + 原生 5 个）

| 按键 | 做什么 | 状态 |
|---|---|---|
| **Cmd+Shift+A** | 批注：选中文本 → 选标签（Tips/错误/提问/关键点）+ 理解度三态 → 写成 callout + 实时记入 Graphiti | ✅ 实绑 |
| **Cmd+Shift+D** | 派生：选中文本 → 选关系类型（7 类）+ 写原因 → 本地建节点 + 双链 + 原因记入 Graphiti。**一键身兼两流程**：在原白板=派生概念节点；在检验白板=考中拉疑问节点（自动挂回原白板+关联被考节点） | ✅ 实绑 |
| Cmd+P | Obsidian 命令面板 — 其余全部插件命令的入口 | 原生 |
| Cmd+G | Graph View 看 wikilink 拓扑 | 原生 |
| Cmd+E | 切换阅读/编辑视图（看渲染后的 callout） | 原生 |
| Cmd+Click | 点 [[wikilink]] 跳转节点 | 原生 |
| Cmd+S | 保存（仅在 Quick Exam 考察文件里有特殊效果=触发自动评分） | 原生 |

## 二 · 原白板流程 — 每步怎么触发

| 步骤 | 触发方式 | 背后发生什么 |
|---|---|---|
| 1. 建板 | **Cmd+P →「建/配置原白板」**（主路径，<300ms 零 LLM）；或 Claudian 输 `/configure-whiteboard from <md>`（旧版 fallback，15-30s） | 本地建 `原白板/<板名>.md`，种子笔记可 move/copy 进节点池 |
| 2. 追加笔记到板 | Cmd+P →「把当前笔记追加到已有原白板」 | 选板 → 查重 → 笔记入节点池 + 白板加 wikilink |
| 3. 派生节点 | **Cmd+Shift+D** ✅ | 建节点+双链+替换选中文本；派生原因**实时记入 Graphiti** |
| 4. 打批注 | **Cmd+Shift+A** ✅ | 本地 callout；批注**实时记入 Graphiti**（另有 3 秒防抖批量兜底） |
| 5. 理解度勾选 | 直接在 callout 里勾 checkbox（无需命令） | **全自动**同步进 frontmatter tips[] |
| 6. 节点对话 | Cmd+P →「节点对话」（⚠️ 文档说 Cmd+Shift+C，**没绑**） | 收集节点上下文写剪贴板 + 自动切 Claudian → 你粘贴 |
| 7. 检索增强对话 | **全自动**（每次在 Claudian 提问，enrich-hook 注入相关笔记）；或手动输 `/chat-with-context` | 注入带 wikilink 的相关片段（昨日修复后：相关才注入，无关 0 打扰） |
| 8. 看图谱/复盘 | Cmd+G 图谱；Cmd+P →「打开 Dashboard.md」 | Dashboard dataviewjs 自动聚合 |

## 三 · 检验白板流程 — 每步怎么触发

| 步骤 | 触发方式 | 背后发生什么 |
|---|---|---|
| 1. 出题 | **Claudian 输 `/start-exam-board`**（主路径）；或 Cmd+P →「启动考察」/Dashboard 🚀 按钮（这两个只是把命令复制进剪贴板引导你去粘贴） | 选最薄弱节点 → 引用你批注出 1 道针对题 → 建 `检验白板/<板名>-<时间戳>.md`（信息隔离：不读定义正文） |
| 2. 答题 | **md 编辑器手写**，写在答题区 sentinel 之间 + 填理解自评 | ⛔ 检验白板**没有** Cmd+S 自动评分——写完要走下一步 |
| 3. 提交评分 | **Claudian 输 `/quiz-answer`** | 静默 4 维评分（不当场显分）→ 掌握度 EMA 演化 → 轻量疑问自动归纳回原节点 |
| 4. 考中拉疑问节点 | **Cmd+Shift+D** ✅（同一个键，自动识别检验白板场景） | 疑问节点挂回原白板 + 关联被考节点 |
| 5. 错误候选处理 | Cmd+P →「接受错误候选」/「异议错误候选」 | 移入正式错题/标异议（⚠️ 目前只有 UAT 测试候选可操作，自动生产管道 B4 待修） |
| 6. Quick Exam 旁路 | Cmd+P →「Quick Exam（单题考察）」（⚠️ 文档说 Cmd+Shift+Q，**没绑**）→ 答题 → **Cmd+S 保存即自动评分** | 后端 LLM 出题（昨日复活）→ 文件底部追加评分反馈（不写掌握度，正式记录走 /quiz-answer） |
| 7. 复盘 | Cmd+P →「打开 Dashboard.md」 | 考察历史聚合（T6） |

## 四 · 全自动环节（你不用做任何事）

1. **enrich-hook 检索注入** — 每次 Claudian 提问自动带上相关笔记（出题/评分轮按隔离铁律自动跳过）
2. **理解度/批注 → frontmatter 同步** — 编辑 callout 即同步
3. **批注 → Graphiti 批量兜底** — 3 秒防抖；后端重启时还有全量回填双保险
4. **Quick Exam 保存即评分** — 仅对本次会话创建的考察文件生效（⚠️ Obsidian 重启后旧考察文件不再自动评分——已知实现缺陷，遇到别当 bug）
