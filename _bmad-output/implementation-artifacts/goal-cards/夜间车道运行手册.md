## 3. ⛔ 夜间禁止动作清单（白名单外一律不做）

| 禁止 | 说明 |
|---|---|
| **不 push** | 任何远程写操作（push / PR / force push）留给白天用户知情时执行。CI 四 job 验绿属 push 后动作，同样不归夜间。 |
| **不删文件** | 包括"看起来是死代码"的文件。孤儿测试等用配置层绕过（见 §4），删除权在用户。 |
| **不碰 canvas-vault 用户内容** | `canvas-vault/` 下的笔记、白板、`节点/*.md` 是用户学习数据。卡片明确要求改的模板文件（如 A2 的 worktree 副本 Dashboard.md）除外；live vault（主仓 `canvas-learning-system/canvas-vault/`）一律不碰。 |
| **不装依赖** | 不 pip/npm install 新包。例外：卡片档案明确把 venv 重建列为预期动作时（如 CARD-B1），仅限重装 requirements.txt 已声明的内容。 |
| **不裸 `git stash`** | stash 栈全 worktree 共享，会弹掉其它 session 的改动。需要暂存用 WIP commit。 |
| **不 kill claude 进程** | session 状态难恢复（用户明令）。 |
| **不越卡边界** | 只改本卡档案列出的文件；遇产品语义岔路选卡片"设计要点"写明的方案，不自创；发现相邻 bug 记录到手册/验收单，不顺手修。 |
