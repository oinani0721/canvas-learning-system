## 1 · 🎯 一句话目标

让系统「越考越准」：考察记录真正喂回系统（不再写完就丢），检索结果干净（不再拿测试数据和重复内容糊弄你），你说「不会」也算数，拆分节点时的困惑被永久记住。

## 2 · 📖 你的视角

作为一个用检验白板考自己的学习者，我想要：
- 系统**记得**我考过什么、错过什么、弃答过什么，下次出题避开重复、打中弱点；
- 我问「我之前学过什么」时，答案来自**我真实的学习记录**，而不是编的，也不是测试垃圾数据；
- 我派生新节点的那一刻「当时为什么困惑」被记下来，以后回看有据可查。

## 3 · 🖥️ 交互流程（你的屏幕会发生什么）

```
你在原白板选中一段文字 → Cmd+Shift+D 派生
        ↓ 屏幕上
新节点文件打开，顶部属性区多了「派生时间」和「当时的掌握档」

你在侧栏输入 /start-exam-board
        ↓ 屏幕上
回执告诉你选了哪个节点考、这是第几次考、为什么选它
（若你某节点一直自评很高但考分低 → 你会看到一道「找反例」型的题）

你在检验白板写答案（或者写「不会」）→ /quiz-answer
        ↓ 屏幕上
静默回执（不显示分数）；节点属性区的掌握度悄悄更新；
vault 根目录出现一个叫 learning_events 的流水账文件，多了一行记录

你在侧栏问「我之前有哪些误解」
        ↓ 屏幕上
回答开头引用你真实的学习记录（查不到时明说查不到，不编）
```

## 4-B · 👤 你来验（10-15 分钟，只用 Obsidian）

> 每条按「我做 X → 我看到 Y → 我感觉 Z」核对。看到的与写的不符 = 不通过，去第 6 段批注。

**① 派生快照**
- [x] 我打开任意原白板，选中一段还没拆出去的文字，按 `Cmd+Shift+D` 派生 → 我看到新节点文件打开，顶部属性区里有 `derived_at`（派生时间），如果源笔记本身有掌握度，还有一条「派生时掌握档」→ 我感觉「我当时的状态被记下来了」。

**② 考察选点讲道理**

> 整板考察 vs 定向考察的关系（回应你的批注）：**整板考察升级更完整，只多不少**。
> 不带参数 = 整板路径：先跑「选点」——扫这块白板的所有节点，没考过的先轮询、
> 考熟的低分节点让位、久不考的重新入围，输出一份 `pick / μ / σ` 排序表选出最该考的。
> 带 `node <节点名>` = 定向路径：你指定谁就考谁，跳过选点。
> **选完之后**的所有新能力（校准考察、题目去重、第 N 次考察）两条路径完全一样，
> 都按被考节点判定。下面第二条用定向只是为了保证你立刻看到「校准考察」题型——
> 整板考察同样会触发它，只是那一板轮到谁由排序表决定。

- [x] 我在侧栏输入 `/start-exam-board`（不带参数，整板考察）→ 我看到回执前有一份每行 `pick / μ / σ + 节点名` 的排序表，选中的是第一名，回执里写了节点名和「第 N 次考察」→ 我感觉它不是随机抽的，而是挑了个该考的，且没考过的节点不会被冷落。
- [ ] （可选，如果你有个自评一直很高、考试却总答不好的节点）我对它定向考 `/start-exam-board node <节点名>` → 我看到题目是「找反例 / 辨析像不像」的型式，回执标了「校准考察」→ 我感觉它戳中了我可能的「假懂」。

**③ 弃答也算数**
- [x] 我在检验白板的作答区只写「不会」三个字 → 输入 `/quiz-answer` → 我看到回执正常完成（没有骂我没作答），并提示疑问已归纳 → 我打开被考的节点，底部多了一条「此题弃答」的疑问块 → 我感觉「不会」本身被当成了有用的信号，心里没负担。

**④ 流水账在长**
- [x] 我在左侧文件列表打开 vault 根目录的 `learning_events` 文件 → 我看到刚才的建板、答题（或弃答）各占一行，带时间 → 我感觉每步学习都有案底，不怕丢。

**⑤ 考过的不重复**
- [x] 我对同一个节点再建一张检验白板 → 我看到新题换了角度，没有把上次的题原样再出一遍 → 我感觉它记得考过我什么。

**⑥ 记忆问答不编**
- [x] 我在侧栏问「我之前有哪些误解？」或「上次学了什么？」→ 我看到回答里引用的是我真实写过/考过的内容（每条带来源），或者明确说「记录里没查到」→ 我感觉它诚实，不再拿一堆不相关的东西糊弄我。
- [x] 我用中文问一个我笔记里用英文记的概念（比如问「协方差矩阵和特征向量的关系」——v4 修正：原示例「极小极大」在库里还没有内容，举错了例子）→ 我看到英文笔记内容（eigenvectors of the covariance matrix…）也被找了出来 → 我感觉中英文笔记终于打通了。

**⑦ 否认过的不再来**
- [x] （可选，需要有待复盘的错误候选）我在节点里看到一条 AI 提名的错误候选并选择「有异议」→ 之后对该节点考察 → 我看到题目不再引用我否认过的那条内容——**即使那条内容换了个说法、多了个标点也一样被挡**（v3 强化）→ 我感觉我的否认被尊重了。

**⑧ 打批注立刻可被记住（批次5'，v3 新增）**
- [x] 我在任意节点里用 `Cmd+Shift+A` 打一条**疑问**批注（写下真实困惑）→ 等一分钟 → 我在侧栏问相关问题 → 我看到回答引用了我刚才的疑问 → 我感觉「刚想到的问题它已经记住了」，不用等到会话结束。
- [ ] （可选）我打一条**错误**批注（记录我犯过的错）→ 稍后我看到该节点出现一条待复盘的错误候选，等我确认——而不是 AI 擅自定案 → 我感觉主权在我。
