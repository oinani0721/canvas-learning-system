# FSRS v2 真实到期调度 — mini 验收单

## 1. 🎯 一句话目标

复习系统从「每天排个先后」升级为「知道每个知识点哪天该复习」——会的东西间隔越拉越长，不会的当天就回炉，某天没到期的它会诚实放你一天假。

## 2. 📖 你的视角

作为学习者，我想让系统替我记住每个知识点的最佳复习时机，以便我把时间只花在「刚好快忘」的内容上。

## 3. 🖥️ 交互流程

考一场评一次分 → 节点自动获得「下次到期日」→ 每天 9:05 只推**今天到期**的内容 → 都没到期时推送说「休息一天」→ Dashboard 的「FSRS 到期」显示真实数字。

## 4-A. 🤖 Claude 已代验

- ✅ 38 项回归测试全绿（四档映射边界 / 新卡零迁移 / 间隔扩张 / 当日重学 / Easy>Good / 序列化往返 / 降级路径 / WHEN 过滤 / 放假消息 / 退役 404）
- ✅ 端到端实测：真实评分链两连考——首考进 Learning（+10 分钟）、二考毕业进 Review（+2 天），幂等复跑零改动
- ✅ 独立对抗性审查 0 CRITICAL，8 项发现全部修复复验（含「降级不清零调度历史」「路径不系于 dev worktree」两条 HIGH）
- ✅ 幽灵调度器与永空端点已退役（生产实测 404）、插件死命令已删并重建部署、Dashboard 占位已换真实统计
- ✅ 存量 17 个无字段节点 = 新卡视同到期，首日行为与之前完全一致（零迁移）
- ⚠️ 个人化参数拟合（F6）按计划延后——评分数据随日常使用自动积累，无需你做任何事

## 4-B. 👤 你来验（日常使用中自然发生，无需专门操作）

- [ ] **到期日出现**：我考完一场并评分后，打开被考的节点 → 我在属性区看到「fsrs_due」等新字段，有一个未来的日期 → 我感觉这次考察被记进了日程
- [ ] **间隔拉长**：我对同一个节点连续几次答得不错 → 每次考完它的到期日离得越来越远，推荐里也越来越少见到它 → 我感觉系统不再纠缠我已经会的东西
- [ ] **答错回炉**：我某题答「不会」→ 这个节点的到期时间变成十分钟后，当天再生成清单它就回来了 → 我感觉它在趁热补漏
- [ ] **诚实放假**：某天所有节点都没到期 → 早上的推送说「今日无到期节点，按计划推进」而不是硬凑一条 → 我感觉这个系统说话算数
- [ ] **口径一致**：我在 Dashboard 看到的「FSRS 到期」数字，和「今日复习」清单里的到期数对得上 → 我感觉全系统只有一本账
