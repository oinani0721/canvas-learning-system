## 3 本卡未证明什么

1. **未证明召回完整性——没有召回率这个数**。只证了三主题非空（FSRS / 跨vault / README）与两个已知锚
   必命中（计划书 `:494`、08-25 卡文 `:163`）。分母未知：契约 `:132` 的 **T3 broad discovery**
   （`user`/`USer` 异常大小写、role 字段、转述、无冒号编号）与契约 `:82` 的**非 Markdown 容器**
   （Canvas JSON / JSONL / YAML / 对话导出）都不在本脚本覆盖面内。
2. **中文 T1 形态未覆盖，且这是实测后的选择不是遗漏**。契约 `:134` 的「至少覆盖」清单列了
   「用户批注 / 反馈 / 原话」。本树实测：**粗体形态 `**用户批注：` 0 处**；裸形态 35 行 / 21 文件，
   但抽样多为 Claude 自己的行文在**转述**用户（「采纳用户原话：…」「[用户批注：以下片段…]」），
   属 T3 层。纳入会把转述当批注，所以不纳入——但这意味着**若将来真出现中文粗体批注，本工具找不到**。
3. **未检索任何私人 root**。A01 算出 6 个私人 root，脚本只对其中 2 个有落地路径（ROOT-ACTIVE-VAULT /
   ROOT-ANCHORED-PRD）做了拦截；另外 4 个（ROOT-TRANSCRIPTS / ROOT-GRAPHITI-MEMORY /
   ROOT-OTHER-BACKUPS / ROOT-EXTERNAL-PRIVATE-01，含两个 P4-secret）**仓内无路径可拦，只是登记**。
   「默认排除」不等于「那里没有批注」——恰恰相反，用户最重要的批注很可能在 live vault 里，本卡一条没看。
4. **日期是文件级的，不是批注落笔时刻**。三个来源（frontmatter / 文件名 / `git log -1 --format=%cs`）
   都是整份文件的属性；同一文件里的多条批注共用同一个日期。`date_source` 字段把这件事说出来了，
   但没有任何机制能给出「这句话是哪天写的」。
5. **hardlink 别名绕得过路径口径的私人守卫**。三层判据（realpath 前缀 / `canvas-vault` 组件名 /
   PRD basename）全部只看路径字符串，hardlink 与原件共享 inode 却在路径上不留痕迹。要堵它得按 inode
   比对，而那需要先遍历私人子树——与「默认连读都不碰私人面」自相矛盾。本卡不堵，如实登记。
6. **只读门量的是 `_bmad-output`，`.git` 不在它的输入面**。`git log` 子进程的 cwd 会落在仓内，
   本卡通过剃掉全部 `GIT_*`（含 `GIT_TRACE*`）+ `GIT_OPTIONAL_LOCKS=0` 来防它写盘，但**没有**
   对 `.git` 目录做跑前跑后摘要对照，所以「git 子进程零副作用」是论证出来的，不是测出来的。
7. **树摘要看不见 mtime / 空目录 / 权限位 / 软链目标**。`tree_digest` 的输入面只有「相对路径 + 文件字节」。
   新建一个空目录、改一次权限、把软链指向别处而目标内容不变——这四类副作用它一概不报。
8. **协议条款只证了「能套上」**。`git apply --check` rc=0 证明 patch 与主干树协议对得上，
   但主 session 套用后排批流程是否真的照做、G1-2 的开卡小抄工作流能不能跑起来，本卡都没证。
9. **未证明在 Windows / CRLF 下行为一致**。行切分用 `text.split("\n")`（与 `grep -n` 同口径），
   CRLF 文件的每行会带一个尾随 `\r`；本树无 CRLF 文件，未构成测试面。
10. **`--context` 会同时缩小检索面，不只是缩小显示**。`--context 0` 时块只剩 marker 行，
    写在续行里的关键词就找不到了（rc 从 0 翻成 1）。这是当前设计，CLI 帮助文案未写明这一点。
11. **Codex 复核未完成**（配额耗尽，两次 0 字节，见 §2.5）。所以「独立第三方在最终 HEAD 上
    BLOCKER/HIGH = 0」这件事**本卡没有证据**。已有的只是本车道自跑的复核与变异测试——
    自己审自己，按协议 §1 不作验收依据。
12. **内部对抗复核在被审文件改动期间进行**（我边看结论边改代码，期间 HEAD 前进 3 次、
    工作树内容变了 5 次），违反「审查对象须冻结」。直接代价：`review:gates` 反复重新冻结重跑，
    我在提取到它的变异表之后**主动停掉**了它，其结构化结论未产出。
    按「没跑完的探针不产出阴性结论」：变异表里**未列出**的变异体一律按「未测出」处理，不按阴性。
13. **未证明本卡的门对「未被想到的变异」有效**。七杀七只说明这七个被想到的缺口堵上了，
    不是「门是完备的」——变异集本身是人挑的，`gate-mutation-survey-*.txt` 里列的就是全部样本。
