# UAT · CARD-G4-12 检索指标名实修正

> [!info]+ 你不需要碰命令行 — 全部技术验证我已代跑（结果见下）
> 这张卡改的是**指标的名字**，不是指标的算法：把"命中率叫成召回率"的名实谎言改正。
> 判分逻辑、数值、门禁阈值**一个字节都没动**。

## 📌 你需要过目的两个结论

1. **改了什么名**：两个检索回归门禁脚本（memory + vault fork 同病同修）的 `recall@5` / `recall@10` 正名为 **`hit@5` / `hit@10`**（分母是 query 数 = 教科书 hit rate；recall 的分母应是相关文档总数，这两个指标从来不是）。以后看门禁输出，`hit@5 = 63.64%` 就是原来的 `recall@5 = 63.64%`——**数值口径完全不变**。
2. **顺手拆掉一个隐藏地雷**：`compare_with_baseline` 对 baseline 缺键的指标会**静默跳过**（continue 无告警）——若只改脚本不迁 baseline，门禁会"全绿空转"。已加 legacy 别名兼容 + 守卫测试（先红后绿），并记入 `docs/known-gotchas.md` G-METRIC-001。
