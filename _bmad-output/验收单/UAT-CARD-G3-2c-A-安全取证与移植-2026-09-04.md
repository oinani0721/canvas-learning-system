## 三 ⛔ 安全发现：生产文件里的未还原变异体

### 事实

`SKILL.md:216` 在 w7 工作树里是：

```python
if False:  # MUTANT
    raise SystemExit(f"[quiz-answer] event_id 首尾含空白 ({eid!r}) — …fail-closed 拒写…")
```

同一位置在 `56bfe9d4` **commit 版**是正常守卫：

```python
if isinstance(eid, str) and eid != eid.strip():
```

即：**变异脚本把生产守卫改成 `if False` 后没有还原**，残留在未提交工作树里。任何人 `git add` 这份工作树，就会把一个被短路的安全守卫提交进仓库。

### 处置与验伪

**已还原**为 `56bfe9d4` 的原行。这是**恢复**原产品语义，不是新增语义——commit 版证明作者本意就是守卫。
