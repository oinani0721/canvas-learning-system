# 每日复习手机推送 — mini 验收单

## 1. 🎯 一句话目标

每天早上 9:05，你的 iPhone 自动弹一条通知，告诉你今天最该复习哪块白板的哪个知识点。

## 2. 📖 你的视角

作为一个学习者，我想让手机每天主动提醒我「今天该复习什么」，以便我不需要自己记着打开 Obsidian 翻掌握度，久不碰的内容也不会被我遗忘在角落。

## 3. 🖥️ 交互流程（你的屏幕会发生什么）

1. 早上 9:05 → iPhone 锁屏弹出：**「📚 今日复习 · 特征值与特征向量」/「Fundamentals 等 2 节点待巩固 · 已闲置 4 天」**
2. 你打开 Obsidian → `outputs/今日复习.md` → 看到一张按优先级排好的白板表格，每行附一条可以整行复制的开考命令
3. 复制一条命令贴进 Claudian → 生成检验白板 → 手写作答 → 评分后，明天的推荐会自动轮换到新的薄弱点

## 4-B. 👤 你来验（只有这几步，全在手机和系统设置里）

- [ ] **装 Bark**：我在 iPhone 打开 App Store → 搜「Bark」→ 安装并打开 → 我看到 app 里有一串以 https 开头的推送地址 → 我把它整段复制，发给 Claude（对话里直接贴）→ 我感觉这一步很快，不到两分钟

- [ ] **明早看横幅**：第二天早上 9:05 后，我拿起 iPhone → 我看到锁屏上有一条「📚 今日复习」通知，标题里是我真实的白板名 → 我感觉这个系统开始主动为我工作了
- [ ] **看清单**：我打开 Obsidian，进入 `outputs/今日复习.md` → 我看到白板按优先级排序的表格和「一键开考」命令 → 我感觉推荐的确实是我最生疏的内容
- [ ] **闭环轮转**（可选，本周内任意一天）：我照着命令考完一场并评分 → 第二天的通知换成了别的薄弱点 → 我感觉它在跟着我的学习进度走
