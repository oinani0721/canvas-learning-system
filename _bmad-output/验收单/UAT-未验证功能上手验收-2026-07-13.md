## 🔍 上手实测问题记录（2026-07-16 · Claude 代记）

> 来源：2026-07-16 「特征值与特征向量」检验白板全链实测（A2 出题 → A3 手写作答"不懂" → A4 静默评分落 done）。链路本身**首次端到端走通**：A2 未泄题（题目只引用误解半句）、A4 回执零分数零方向（HARD-SILENT 合规）、两阶段提交 + calibration 事件落盘正常。以下是过程中发现的问题，按严重度排列。

### P1 · 纯文本疑问被静默丢弃（A3/A4 · UX 断层）⭐ 本场直接踩中
- **现象**：用户在答题区手写「我对特征向量这个词本身就是不太懂」——这是本场最有价值的学习信号，但因为不是 `> [!question]+` callout 格式，`/quiz-answer` 的疑问归纳 Grep（只认 `[!question]+` / `[!error]+` / `**User：**`）不命中，疑问没有归纳回 `节点/Fundamentals.md`，且全程零提示。
- **影响**：新手最自然的写法（纯文本）= 信号全丢；而 callout 格式的可发现性依赖用户已知快捷键——A2 批注区的提问本身就是证据（用户不知道绑哪个键）。
- **建议方向**：`/quiz-answer` 检测到答案区含疑问语气纯文本时给一次性提示；或把归纳范围放宽到答题区内的显式疑问句。

### P2 · 跨节点素材接口返回 UAT 测试污染数据（C4/T4 · 后端）
- **现象**：`POST /api/v1/exam/targeting-material`（node_id=Fundamentals, vault_id=canvas-vault）返回 `source_node: "UAT-2.5.X-test"`、文本「学生混淆了 admissibility 和 consistency」——CS188 搜索算法内容混进线性代数 vault 的出题素材。
- **影响**：本场因薄弱档规则（mastery < 0.4 不跨概念）才没被引用；一旦目标节点 ≥ 0.4，这条测试种子会被当成"你犯过的真实错误"写进考题（跨学科幻觉污染）。
- **建议方向**：清理 T4 UAT 增殖种子；素材接口按 vault/subject 边界过滤。

### P3 · 掌握度"无字段"在出题链与评分链语义不一致
- **现象**：`节点/Fundamentals.md`（seed note）frontmatter 无任何 mastery 字段。出题链把它当 **0.30 占位档**；评分链 EMA 无旧值时直接 `new = grade_norm`——本场答"不懂"（grade_norm=0.0）后 `mastery_score` 被首评直写 **0.0**，而不是从 0.30 平滑下降。另外白板 Concepts 行内标注 "(mastery: 0.30)" 与节点 frontmatter 实况双源不一致。
- **影响**：同一节点在两条链身价不同；首评一次全错即归零，Dashboard 掌握度曲线出现悬崖跳变。
- **建议方向**：建板/派生时就给节点落 `mastery_score: 0.30` 初值；或评分链无旧值时以 0.30 为 EMA 基准。

### P4 · 派生节点文件名句中截断 + 占位模板长期滞留
- **现象**：`节点/Eigenvalues-are-special-vectors-that-sat.md` 文件名按固定长度在句中砍断（"-that-sat"）；且正文至今是「你的 1-2 句精准定义」占位模板，出题链每次被迫跳过。

- **现象**：用户在已评分落定（status: done）的 `检验白板/特征值与特征向量-2026-07-16-0112.md` 末尾用「插入新疑问」命令写下新疑问（格式完美：`> [!question]+ ❓ 提问 %%cb-mrqiq27bclpk%%` + 疑问正文）——**命令本身验收通过**。但这条疑问当前没有任何链路会拾取：① `/quiz-answer` Step 0 幂等守卫拒绝 done 板重跑；② callout-sync 路径白名单只有 `节点/`+`原白板/`，不含 `检验白板/`；③ 下次考察生成的是新板，旧板批注永不回访。
- **影响**：「考完之后回看时冒出的疑问」是高价值元认知信号，目前写在 done 板上=静默丢失（与 P1 同族，但 P1 是格式问题、P11 是生命周期问题）。
- **过渡走法**：考后疑问直接写到 `节点/<被考概念>.md` 里（同一个「插入新疑问」命令，节点在 callout-sync 白名单内，停笔 3s 自动入库，下次考察该节点时会作为批注素材被引用）。
- **建议方向**：`/quiz-answer` 的 done 拒绝分支增加一个"增量归纳"轻路径（板 done 但发现新增疑问 callout → 只做疑问归纳回节点、不重复评分）；或 callout-sync 白名单纳入 `检验白板/` 并把疑问挂到 `selected_node`。
