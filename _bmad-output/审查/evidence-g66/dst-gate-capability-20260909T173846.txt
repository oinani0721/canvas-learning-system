# 对照四种实现在三个日期上的输出:
2026-03-08T10:00:00  今天 offset=-1 day, 20:00:00
   正确 combine      : 2026-03-09T00:00:00-04:00
   错A 硬搬今天offset : 2026-03-09T00:00:00-04:00  → 与正确相同 ⇒ offset 断言无区分力
   错C 裸 +24h       : 2026-03-09T10:00:00-04:00  → hour=10 ⇒ 被 hour==0 断言抓住
2026-11-01T10:00:00  今天 offset=-1 day, 19:00:00
   正确 combine      : 2026-11-02T00:00:00-05:00
   错A 硬搬今天offset : 2026-11-02T00:00:00-05:00  → 与正确相同 ⇒ offset 断言无区分力
   错C 裸 +24h       : 2026-11-02T10:00:00-05:00  → hour=10 ⇒ 被 hour==0 断言抓住
2026-03-07T10:00:00  今天 offset=-1 day, 19:00:00
   正确 combine      : 2026-03-08T00:00:00-05:00
   错A 硬搬今天offset : 2026-03-08T00:00:00-05:00  → 与正确相同 ⇒ offset 断言无区分力
   错C 裸 +24h       : 2026-03-08T10:00:00-04:00  → hour=10 ⇒ 被 hour==0 断言抓住

结论: 门里承重的是 hour == 0 那条断言; offset 断言在 US DST 下恒真 (切换点在凌晨 02:00,
      今天白天与次日 00:00 的 offset 恒相同)。已在门的 docstring 里如实登记, 未假装加
      一个能区分错A 的 case —— IANA 现行时区里没有 22:00-23:59 切换的。
