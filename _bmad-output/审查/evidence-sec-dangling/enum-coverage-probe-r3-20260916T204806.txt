本版对每个用例**打印**：合成输入(紧凑 JSON) / 实际完整产出(全部 (位置,方案名) 对) /
精确期望集合 / 判定。断言一律是**集合相等**，不是「某名字不在里面」。
生成器一律用 list() 消费(见下方 run() 的第一行)，不存在「只创建生成器没跑主体」。

`discriminates` 字段如实标注该用例能否区分本卡某项加固：
  - True  = 该用例在加固前的代码上会 FAIL(抛异常或结果不同)
  - False = 加固前后都通过, 它只是覆盖性用例, 不作为「加固有效」的证据

脚本不入库(scratchpad)，但其**全文**会被 round-3 存档逐字收录，便于独立核对。

RESULTS = []


def run(name, schema, expected, discriminates, note=""):
    """expected = 精确期望的 (位置, 方案名) 集合。断言是集合相等。"""
    try:
        got = set(list(enumerate_refs(schema)))  # list() 消费生成器, 主体一定执行
        raised = None
    except Exception as exc:  # noqa: BLE001 — 探针要把异常本身当结果记录
        got, raised = None, f"{type(exc).__name__}: {exc}"
    ok = raised is None and got == set(expected)
    RESULTS.append(ok)
    print(f"  [{'PASS' if ok else 'FAIL'}] {name}")
    print(f"        输入   = {json.dumps(schema, ensure_ascii=False, sort_keys=True)}")
    print(f"        实际   = {'抛异常 ' + raised if raised else sorted(got)}")
    print(f"        期望   = {sorted(set(expected))}")
    print(f"        能区分加固 = {discriminates}" + (f"  ({note})" if note else ""))
    return ok
