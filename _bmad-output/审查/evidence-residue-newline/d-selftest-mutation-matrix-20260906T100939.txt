### 自证块承重矩阵 — 每条变体都是「把自证块里那一行换成另一种写法」
# 载荷字节:
#   0000000    a   \  \n   b  \0       c  \0                                
#   0000010
# 期望值(独立字面量, 不由被测量派生):
#   0000000    |   a   \  \n   b   |       c                                
#   0000010
---
== 正控(必须 PASS, 否则自证块本身是死门/误拦) ==
原样: IFS= read -r -d ''               PASS -> 自证放行
    acc=   |   a   \  \n   b   |       c                                

== 变异(每条必须 FAIL, 否则自证块对该性质失明) ==
去掉 -r                                FAIL -> 自证拦下(exit 1)
    acc=   |   a   b   |       c                                        
去掉 IFS=                              FAIL -> 自证拦下(exit 1)
    acc=   |   a   \  \n   b   |   c                                    
去掉 -d '' (退回按行)              FAIL -> 自证拦下(exit 1)
    acc=   |   a   \                                                    
解释器换 dash (无 read -d)          FAIL -> 自证拦下(exit 1)
    acc=

== 对照: 旧载荷 'a\0b\0' (只数条数) 对 -r 的敏感性 ==
  旧载荷 read -r -d ''   -> 条数=2  (两者相同 => 计数判据对 -r 失明)
  旧载荷 read -d ''      -> 条数=2  (两者相同 => 计数判据对 -r 失明)
