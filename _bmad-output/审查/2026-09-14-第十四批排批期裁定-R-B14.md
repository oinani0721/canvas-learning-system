## R-B14-1 lefthook `--no-auto-install` 是 1.x flag，brew 2.1.6 已移除 ⇒ **裸调用**

- **实测**：`/opt/homebrew/bin/lefthook version` → `2.1.6`；`/opt/homebrew/bin/lefthook --no-auto-install version` → `Incorrect Usage: flag provided but not defined: -no-auto-install`，**rc=1** 并打印 usage。
- **危害**：把它当「验证通过」的判据会恒 rc=1 = 假红；若判据写成「rc≠0 即跳过该门」则变假绿。第十三批手册沿用的是 lefthook 1.x 口径。
- **裁定**：本批 lefthook 验证一律 **裸** `/opt/homebrew/bin/lefthook <子命令>`（如 `lefthook version` / `lefthook run pre-commit`），**禁 `--no-auto-install`**，**仍禁 `npx lefthook`**（npx 侧是 1.13.6，flag 语义不同）。
- **落地**：手册 §四.1 第 8 条已改；卡文 T3-C / T8-A / T8-E / T8-G 四份同步改。T8-E 的写者已独立发现并在卡文内标注「手册 §零.8 待更正」——本裁定即该更正。

## R-B14-2 `tests/unit` 基线自证公式：用 `grep -vc '^#'` = **64**，禁 `grep -c '::'`

- **实测**（`evidence-b14/unit-red-baseline-08100483.txt`）：总 **67** 行 = **3** 行 `#` 注释 + **64** 行真 nodeid；`grep -vc '^#'` = **64**；`grep -c '::'` = **65**。
- **根因**：第 3 行注释里逐字引用了一条 flaky nodeid（`test_candidate_service::test_accept_candidate_already_accepted_returns_422`），`grep -c '::'` 会把注释算进去。
- **裁定**：基线自证唯一口径 = `test -f "$BASE" && grep -vc '^#' "$BASE"` → **64**。任何卡文/短 goal 写 `grep -c '::'` 或期望 65 的，改为本条。
