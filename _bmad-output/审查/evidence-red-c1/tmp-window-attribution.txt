=== 附：-rs 标志的语义陷阱（本卡实测，记入台账）===
pytest 的 -r 是**替换**而非追加短摘要类别: 默认 -q 给的是 fE(failed/error),
显式传 -rs 后短摘要**只剩 SKIPPED**, FAILED/ERROR 行消失。
实测(同一 HEAD 的两轮):
  rs-close-20260908T070403.txt (-q -rs) : '^FAILED ' = 0   / '^SKIPPED' = 48
  unit-after-20260908T071053.txt (-q)   : '^FAILED ' = 165 / '^SKIPPED' = 0
⇒ 不能从 -rs 那一轮派生 nodeid 差集(会得到"全部 202 条消失"的假差集)。
本卡的 nodeid 判据自始至终只用 -q 那几轮(unit-open / unit-after), 未受影响;
SKIPPED 判据只用 -rs 那两轮(rs-open / rs-close)。曾一度从 rs-close 派生差集,
当场自查发现并把两个派生文件移出 evidence 目录(未入库)。
若要一轮同时取两者, 应传 -rfEs。
