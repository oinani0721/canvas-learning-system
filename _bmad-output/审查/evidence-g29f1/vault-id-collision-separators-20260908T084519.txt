# vault id 碰撞的分隔符实测（Codex r4 A-4：我的避名保证过窄）
# 2026-09-08T00:45:19Z

  短名 '算法' → sanitize = '算法'
  长名各写法 → sanitize → 是否以 '算法_' 开头（= 会碰撞）:
    '算法进阶'         → '算法进阶'               碰撞=False
    '算法 进阶'        → '算法_进阶'              碰撞=True
    '算法-进阶'        → '算法_进阶'              碰撞=True
    '算法_进阶'        → '算法_进阶'              碰撞=True
    '算法.进阶'        → '算法_进阶'              碰撞=True
    '算法/进阶'        → '算法_进阶'              碰撞=True
    '算法（进阶）'       → '算法_进阶'              碰撞=True
    '算法2'          → '算法2'                碰撞=False
结论: 碰撞条件 = 长名 sanitize 后正好是「短名 sanitize + 下划线 + 其余」；
      空格/连字符/下划线/点/斜杠/全角括号**都**会变成下划线 ⇒ 都碰撞；
      只有直接连写（算法进阶）或紧跟字母数字（算法2）不碰撞。
