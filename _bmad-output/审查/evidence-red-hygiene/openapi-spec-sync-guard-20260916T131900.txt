### 记录时刻: 20260916T131900（本卡 CARD-RED-HYGIENE，第十四批 T10 第 5/5）

lefthook.yml:62-73 原文（glob 正是 backend/app 下的 config.py —— 本卡改了它）:

    spec-sync-root:
      glob: "backend/app/{main.py,config.py}"
      run: |
        if [ -f "backend/.venv/bin/python" ]; then PY="backend/.venv/bin/python"; else PY="python3"; fi
        echo "[Spec Sync/root] API changes detected, regenerating backend/openapi.json (via $PY)..."
        if ! "$PY" scripts/spec-tools/check-openapi-drift.py --write backend/openapi.json; then
          echo "[Spec Sync/root] FAILED — 快照未能重生成, 先修好再 commit(禁手改快照)。"
          exit 1
        fi
        git add backend/openapi.json || exit 1
        echo "[Spec Sync/root] + backend/openapi.json staged"
