# CARD-G6-9c-R2 承重脚本（入库以便复核）

Codex r5 指出「目录未留执行脚本，无法进一步核实 `atexit` 注册和异常退出恢复」——
这几份就是本卡承重判据的实际执行体，原样入库。

| 脚本 | 作用 |
|---|---|
| `negctl.py` | **二十段负控 runner**。每段只拆一层防线；`atexit.register(restore)` 无条件还原；三个被改文件 `shasum -a 256` 跑前跑后逐字比对；每段绑定具体失败消息；⑥⑦ 做区分性互斥判定。开跑前有**锚点预检**（遍历所有段、断言每个变异锚点在每个目标文件恰好命中 1 次）——本卡两次踩到「锚点随生产代码演进失效、脚本跑到一半才中止」才加的。 |
| `sync_copies.py` | 两份 TZ 副本的**共享段同步与同源核验**（模块 docstring 之后的全部逐字节比对 + sha256）。`check` 只报告，`apply` 以 `scripts/local_tz.py` 为源同步到 `backend/app/core/display_tz.py`。 |
| `candwin.py` | 候选年上界的穷举验证：4088 个规格 × 873 个探针时刻，对比 `(y-1,y,y+1)` / `(y-2,y+1)` / `(y-3,y+2)` 三种候选窗与 C 库的分歧数。 |
| `endrule.py` | 省略规则的 end 切换时刻验证：2007..2037 秋季回拨窗逐分钟（156 万点），对比「写死当地 02:00」与「`3600 + dst_off − std_off` 现算」两种写法。 |

⚠️ 这几份跑在 scratchpad 隔离子目录里（scratchpad 根目录被并发会话放过 `select.py`，
会遮蔽 stdlib）。路径是绝对路径，复核时按需改 `ROOT`。
