## 二、核心裁决采纳：三平面架构

**用户的 Graphiti 初衷判定**：「需要图」是对的，错在「需要图 = Graphiti 负责所有图」。

```
frontmatter                    = 当前事实唯一可写真相源（保留现有契约，加稳定 ID）
Neo4j 确定性结构投影            = 精确回答「白板怎么拆解」（100% 完整性契约，projector 唯一写方）
Graphiti                       = 时间记忆（何时问过/曾经误解/何时变化），只引用 stable node_id
LanceDB                        = 正文语义召回（必须先结构限域再搜）
原白板 ## Concepts              = 改为自动生成视图，废除第二真相源
```

关键论据（已采信）：Graphiti 的实体经 LLM 抽取产生，适合「相关性检索」不适合「一个都不能漏的完整性契约」；结构完整性必须走确定性投影。同一 Neo4j 容器承载两套逻辑图（结构图 projector 写 / 时间图 episode worker 写），互不补齐。

## 四、其余采纳要点

- **选题多维化**：μ−σ 保留为一维，加 FSRS due/calibration gap/repetition penalty/relation coverage 等
- **54 条结构 golden set**：结构检索硬门槛 Precision=Recall=1.00（语义可近似，结构不许「差不多」）+ 新鲜度/注意力预算/考试安全四组量化门槛
- **exam-safe 视图禁项清单**（不含正文/定义/correction/evidence）——现有信息隔离铁律的 API 化
- **注意力对策定调**：「先导航后阅读」（Aider repo map / Claude Code 官方 subagent 模式），不是更大上下文
- 多 vault 是第一层分区非最终架构；RAPTOR 只适合转录语义层不替代结构图
