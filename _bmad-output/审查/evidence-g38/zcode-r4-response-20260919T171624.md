## ② 按重要性回答

**Q0（身份映射）——未找到跨 vault 写路径。** 防线是四层，形态校验不是唯一防线：① `--group-id` 形态门（`vault__<id>` 物理格式）；② **vault 自报身份绑定**（`assert_group_matches_vault`，`:317` 起）：`group_id` 必须逐字等于 `vault__<vault_id>`，二级作用域必须显式 `--group-scope`（r2 BLOCKER-1 的前缀歧义被逐字相等封死，`vault__alpha__beta` 冒充路径有专项负控）；③ JSON 侧行过滤是 `group_id` **等值**（`collect_json_targets` `:671`）；④ Neo4j 三条查询（读 `:691-697` / 写 `:699-704` / 清 `:706-711`）对 `c` 与 `r` **两个 alias 都过滤** `$gid`——R1 全覆盖成立，与生产写方 `neo4j_client.py:1030-1031` 的复合身份键对齐。已如实登记的残余假设（census §四「仍未证明的部分」）：`.canvas-config.yaml` 自报身份与目录真实归属的一致性是信任锚，脚本不证明 vault「没谎报」——这是设计边界，非缺陷。

**Q1（整秒归一）——除亚秒外不吞真分歧。** 真相源按构造只有整秒分辨率（`_FM_DUE_SHAPE` `:111` 不收小数秒），整秒比较精确等于真相源分辨率；亚秒差不是真相源能表达的分歧。时区各口：JSON naive 默认按**本地**解释（与 `neo4j_client.py:717-718` 写 / `:794/:808` 读两侧 naive 同型的代码可证契约），`--json-naive-tz utc` 是显式改口径且结论真的会变（test `:694-703`）；**夏令时边界的 naive 本地值判 ambiguous 不写**（fold0≠fold1 → `ambiguous_local_time` / `nonexistent_local_time`，`test:964-986`，含非边界对照输入防哑闸）；Neo4j 侧 naive 值无契约 → `naive_without_proven_contract` → ambiguous；不可解析/非字符串 → ambiguous。还原校验另用 `_same_instant_exact`（`:1453-1474`）补比原始小数秒位，r2 MEDIUM-7 的纳秒吞噬已封（test `:1069-1083`）。
