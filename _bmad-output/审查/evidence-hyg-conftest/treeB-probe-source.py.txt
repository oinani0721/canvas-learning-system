"""U10-A (n) 树 B 探针 —— 只存在于临时 worktree `u10a-treeB-negctl`，不入库、不 commit。

模拟「**别的** worktree 在树 A 的 session 窗口内往全机共享 `/tmp` 建出匹配目录」这一
真实并发形态（Codex Y6-A HIGH #1 描述的假红成因）。

⚠️ 只建**空目录**（`rmdir` 可清），不建 vault 骨架 —— 卡文 §三 禁递归删除，

import os
from pathlib import Path


def test_treeb_creates_shared_tmp_dir():
    target = Path("/tmp") / ("test-vault-treeB-" + str(os.getpid()))
    target.mkdir(exist_ok=True)
    assert target.is_dir()
    print("TREEB_CREATED=" + str(target))
