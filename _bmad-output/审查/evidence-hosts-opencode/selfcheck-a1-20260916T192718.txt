# A1 自查：删掉 shell 侧物理核后，python 侧是否覆盖了它原本的全部性质
#（形状：「统一 helper 会删掉一条规则」—— 删除前必须逐条对照）

性质                                            shell 旧段有   python 侧有
① 软链在位（是 symlink）                                     是         是 ✅
② 软链目标串逐字相符                                           —         是 ✅
③ 软链自己落在 vault 内                                      是         是 ✅
④ 目标 = 本 vault 的同名技能目录                                是         是 ✅
⑤ .agents / .agents/skills 本身不是软链（非整目录级）              —         是 ✅

结论：shell 旧段覆盖的 ①③④ 在 python 侧都有对应，且更强 ——
  · ③ 由 vfd→afd→sfd 的 fd 链**结构性**保证（symlink 只能建在那个 fd 指的目录里），
    不是路径前缀字符串比较；
  · ④ 比 (dev,ino) 而不是比路径字符串，钉的是 inode 不是名字；
  · ② 是 python 侧**多出来**的一条（目标串逐字相符），shell 旧段没有。
  ⇒ 没有性质随删除一起丢掉。
