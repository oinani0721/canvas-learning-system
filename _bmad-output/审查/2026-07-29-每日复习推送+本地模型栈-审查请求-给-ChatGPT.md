```python
GAMMA_DAILY = 0.99  # σ 半衰期 ≈ 69 天
def effective(a, b, days_idle, gamma_daily=GAMMA_DAILY):
    f = gamma_daily ** max(0.0, days_idle)
    return max(a * f, FLOOR), max(b * f, FLOOR)
```
