with a ChatGPT account。确定性复现，不是限流（限流是 429 且会给重置时间），
也不是未登录（codex login status 报 Logged in）。

⛔ 追加实测（2026-09-19 05:5x）：这台机器上**根本没有可用的 OPENAI_API_KEY**，
所以「printenv OPENAI_API_KEY | codex login --with-api-key」这条指令是无效的：
  · 进程环境: OPENAI_API_KEY set=False（对照锚: GOOGLE_API_KEY set=True, len=39
    ⇒ 证明本 shell 确实加载了用户 profile，不是「没读到 .zshrc」）
  · ~/.zshrc / ~/.zshenv / ~/.zprofile: grep -c 'OPENAI_API_KEY' 全部 = 0
  · keychain: security find-generic-password -s codex ⇒ item could not be found

⇒ 用户需要**自己拿一个有 gpt-6-astra 权限的 key** 喂给它，例如在自己的终端里:
    export OPENAI_API_KEY='...'; printenv OPENAI_API_KEY | codex login --with-api-key
  （或任何等价方式。key 不要贴进对话。）
解除后可用 `codex login status` 确认 auth_mode 变成 apikey，再用
`codex debug models | head -c 2000` 确认 gpt-6-astra 出现在清单里。
