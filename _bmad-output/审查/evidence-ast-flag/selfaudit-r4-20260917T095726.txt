   下一张卡若把变异目标指向 '同名工厂重定义'，会重蹈 Codex r3-LOW4 那个覆辙而断言不报警。

--- Q4 索引自检的覆盖面窄于它的主张 ---
README 声称「本文件引用的每个具体文件名都必须真实存在」，但捕获正则只认
「反引号包裹 + 受限字符集 + 小写扩展名」。实测四种形态**全部静默漏过**（捕到 0 个引用）：
  ① 大小写不同        `GREEN-…TXT`
  ② 带目录前缀        `evidence-ast-flag/green-….txt`
  ③ 反引号内带空格    `green-63-28 20260917T094933.txt`
  ④ 完全没用反引号    裸写文件名
控制组（真名带反引号）正常捕获并判存在。
⇒ 判据取的面 < 它的主张。处置：要么放宽捕获、要么收窄声称 —— 本卡按「收窄声称 + 补一条
   『带已知扩展名但没用反引号包裹的 token 也要报出来』」处理，不做无谓放宽（放宽要配白名单，
   因为 README 合法引用了几个不在本目录的文件）。
